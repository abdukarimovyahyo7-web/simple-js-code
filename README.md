# JS Division Examples

A simple JavaScript project that performs basic division operations.

## About

This project contains 5 division examples solved using JavaScript, with results printed via `console.log`.

## Examples

| Variable | Expression | Result |
|----------|------------|--------|
| misol_1 | 25 / 5 | 5 |
| misol_2 | 500 / 10 | 50 |
| misol_3 | 105 / 5 | 21 |
| misol_4 | 100 / 20 | 5 |
| misol_5 | 55 / 5 | 11 |

## How to Run

```bash
node index.js
```
